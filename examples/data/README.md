# Data card: the book's data

Every dataset the examples read is listed here, with its source, its licence and how it is stored. Examples read data only from this folder, and model outputs only from `recorded/`.

| Folder | What it holds | Source | Licence | Stored as |
| --- | --- | --- | --- | --- |
| `shop/` | The shop's warehouse: generated in memory by `lib/shop_data.py` from one fixed seed. Only its column descriptions, glossary, verified queries, roles (`roles.toml`) and chapter 9's access probes (`access_probes.toml`) are committed | Generated by the book's own code | Generator MIT; documents CC BY 4.0 | Code and TOML; no generated rows committed |
| `semantic/` | The shop's semantic models and metrics | Written for the book | CC BY 4.0 | YAML |
| `golden/` | The shop's golden questions, their golden SQL and the role each is asked as | Written for the book | CC BY 4.0 | TOML |
| `dabstep/` | Three of DABstep's public dev tasks and its payments table, without four identifier columns, with the dataset's own `LICENSE` | DABstep, `adyen/DABstep` on Hugging Face at revision `1d740a5`; `SOURCE.md` lists every change | CC BY 4.0, which this folder keeps | JSONL and gzipped CSV, with `LICENSE` and `SOURCE.md` beside them |
| `recorded/` | Model replies, agent traces and judge verdicts, one folder per recording, each with a `manifest.json` | `recordings/` scripts, pinned model | CC BY 4.0 | JSONL |

The names, emails and other personal fields in the shop are synthetic and can't reach anyone: emails use the reserved domain `example.com`, phone numbers are masked to their last two digits, and no card or bank numbers are generated.

Chapter 9's `access_probes.toml` holds two replacement product names that carry a sentence addressed to the model that summarises a result. They are synthetic, target only that summary in the book's own data, and are applied only to a temporary copy of the warehouse (`lib/untrusted.py`).
